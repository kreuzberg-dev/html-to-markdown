API Reference¶

This page documents the public interface of the demo package.

demo.connect(host, port=8080)¶

Opens a connection to the given host and port.

Parameters:

  • host (str) – the hostname to connect to.

  • port (int) – the TCP port, defaults to 8080.

Returns:

an open Connection object.

Return type:

Connection

Note

The connection is not automatically retried on failure. Wrap calls to connect() in your own retry loop if the remote host is unreliable.

Example usage:

import demo

conn = demo.connect("localhost", port=9090)
conn.send("ping")
class demo.Connection¶

A handle to an open connection returned by connect().

close()¶

Closes the connection and releases the underlying socket.
