Release Runbook

Draft — v0.3

Pre-flight checks

Run through this list before cutting a release. Steps marked with bold emphasis block the release if skipped.

  1. Freeze the branch and announce in #releases.
  2. Run the full test matrix on CI.
  3. Bump the version in the manifest and changelog.

Rollback plan

  • Revert the tag if smoke tests fail within 30 minutes.
  • Page the on-call engineer listed in the on-call schedule .
