Migration Guide

This guide covers moving the shared database cluster to the new region. Read the whole document before starting; the process is not fully reversible past step 4 . 1

Confirm you have write access to the target project before proceeding, and that the maintenance window has been announced.

  1. Snapshot the source cluster.

  2. Provision the target cluster with matching instance_type.

  3. Replicate data and verify checksums before cutover.

Rollback is only supported before step 4:

  • Stop replication.

  • Point traffic back at the source cluster.

1 Steps 1-3 write only to the target cluster and can be safely re-run.
