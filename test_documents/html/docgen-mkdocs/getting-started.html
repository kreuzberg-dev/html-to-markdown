Getting Started¶

This guide walks through installing the demo CLI and running your first command.

Installation¶

Note

The CLI requires Python 3.10 or newer. Check your version with python --version before continuing.

$ pip install demo-cli
$ demo --version
demo 1.4.0

Configuration Options¶

Option Default Description
--config ./demo.toml Path to the configuration file.
--verbose false Enable verbose logging output.
--timeout 30 Request timeout, in seconds.

Warning

Setting --timeout below 5 seconds may cause requests to large hosts to fail spuriously.
