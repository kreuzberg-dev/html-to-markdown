Quick Start​

Follow the steps below to get the demo SDK running in a fresh project.

Tip

Node.js 18 or later is required. Older versions are not tested in CI.

Install the SDK​

npm install @demo/sdk

Initialize a client​

import { Client } from '@demo/sdk';

const client = new Client({ apiKey: process.env.DEMO_API_KEY });
Caution

Never commit DEMO_API_KEY to version control. Load it from an environment variable or secret manager instead.
